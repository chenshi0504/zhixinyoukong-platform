# 信号配时配置文件

此目录存放信号优化所需的配置文件（XML格式）。

## 文件说明

| 文件 | 说明 | 是否必需 |
|------|------|----------|
| `signal_config.xml` | 信号配时参数（决策变量、相位、周期等） | 可选（自动生成） |
| `flow_data.xml` | 路段流量数据（饱和流率、需求流量） | 可选（自动生成） |
| `turn_ratios.xml` | 转向比数据 | 可选（自动生成） |

## 自动生成

如果这些文件不存在，系统会在首次运行时自动从路网提取并生成。

## 手动生成

运行以下命令手动生成配置文件：
```bash
python src/2_2_signal_data_extractor.py
```

## 参数说明

- 默认相位时长：30秒
- 绿灯时间下限：10秒
- 绿灯时间上限：60秒
- 无黄灯时间（Siouxfalls路网特性）
