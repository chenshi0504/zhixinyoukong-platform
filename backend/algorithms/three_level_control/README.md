# 三层级协同控制模块

## 模块简介
车路云一体化的三层级协同控制系统，整合信号优化、路径诱导、车速控制三个层级，实现全局交通优化。

## 算法原理

### 三层级架构
1. **上层（信号优化）**: 交叉口信号配时优化
2. **中层（路径诱导）**: 路网路径规划和诱导
3. **下层（车速控制）**: 单车速度控制和协同

### 协同优化
- 层级间信息共享
- 分布式决策
- 全局目标优化

## 主要功能
- 三层级联合优化
- 分层独立控制
- 协同效果评估
- 多场景仿真

## 使用方法

### 参数说明
| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| enable_signal | bool | true | 启用信号优化 |
| enable_routing | bool | true | 启用路径诱导 |
| enable_speed | bool | true | 启用车速控制 |
| coordination_mode | str | full | 协同模式（full/partial/none） |

### 运行示例
```bash
cd backend/algorithms/three_level_control
python run_coordination.py --mode full
```

## 输出结果
- **协同控制结果**: `output/coordination_result_{timestamp}.json`
- **性能对比图**: `output/performance_comparison_{timestamp}.png`

## 性能指标
- **系统总延误**: 所有车辆的总延误时间
- **平均速度**: 路网平均行驶速度
- **能耗**: 总能源消耗
- **协同增益**: 相比单层控制的改善百分比

## 常见问题

### 1. 协同效果不明显
**解决方案**: 检查各层级参数配置，增加CAV渗透率，调整协同权重

### 2. 计算时间过长
**解决方案**: 使用分布式计算，减少仿真时长，降低路网规模
