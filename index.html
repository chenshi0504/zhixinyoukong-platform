平台简介

平台面向交通工程、智慧交通、管理科学与工程专业，采用「本地桌面端 + 云端管理端 + 硬件在环」三形态： 本地端在 Windows 上一键安装、断网可用，承担算法实验；云端管理端供教师发布任务、评阅报告、查看统计； 硬件在环通过 MQTT/ROS 把算法下发到真实智能小车，在校园点云地图上完成虚实闭环验证。

本页是托管在 GitHub Pages 上的静态文档站，用于介绍平台、查阅手册与下载源码。 平台后端依赖 FastAPI / SUMO / CARLA / GPU，无法在 GitHub Pages 上运行； 若要在线做实验，请按 部署说明 把云端管理端部署到服务器或容器平台。

功能模块

多源数据采集

YOLO11 目标检测与跟踪，视频车辆检测、分车型流量统计与精度比对。

多源数据融合

贝叶斯决策级融合，结合检测置信度与点云熵，量化融合增益。

交通流重构

DTALite 动态分配与交叉口转向流量 OD 反推，由有限观测重建路网状态。

交通流预测

线性回归、随机森林、决策树、LSTM、GRU 多模型对比与误差分析。

交通信号优化

Webster、HCM、BO、TuRBO、MPC-TuRBO、GA、PSO、DQN、PPO 配时优化。

路径诱导

Dijkstra、A*、Floyd、SSP 与动态路阻下的路径规划与诱导评价。

车速控制

PID、MPC、ACC、CACC、IDM，跟踪误差与舒适性权衡实验。

三层级协同优化

信号—路径—速度联合优化，单层 / 双层 / 三层效果定量对比。

虚实结合仿真

SUMO + CARLA 联合场景、算法批量测试、MQTT/ROS 实车回环。

教学管理

任务发布、学生与分组管理、报告在线评阅、过程性成绩统计。

快速开始（本地）

# 1. 安装 Python 3.10+（勾选 Add to PATH）
# 2. 双击「启动平台前后端.bat」，或：
cd backend
pip install -r requirements.txt
python run.py

# 3. 浏览器打开
http://localhost:8000

外部依赖：SUMO 1.21+（信号/路径/车速实验）、CARLA 0.9.15（虚实仿真，需 NVIDIA 显卡）、DTALite（随包提供）。

首次运行默认账号 admin / teacher / student，初始密码均为 123456；对外提供服务前务必修改。
