# 智信优控云端平台部署指南

## 概述

云端平台是智信优控的管理中枢，负责：
- 用户注册和认证
- 机构和班级管理
- 任务下发和报告收集
- 数据同步

**重要**: 云端平台必须运行，本地平台才能使用注册、任务下发、报告上传等功能。

---

## 系统要求

- **操作系统**: Linux / macOS / Windows
- **Python**: 3.9+
- **数据库**: PostgreSQL 12+ 或 SQLite（开发测试）
- **内存**: 2GB+
- **CPU**: 2核+

---

## 快速部署（本地测试）

### 步骤 1: 安装依赖

```bash
cd cloud/backend
pip install -r requirements.txt
```

### 步骤 2: 配置数据库

**使用 SQLite（开发测试）**:
```bash
# 创建 .env 文件
cat > .env << EOF
DATABASE_URL=sqlite:///./cloud.db
SECRET_KEY=your-secret-key-change-this-in-production
EOF
```

**使用 PostgreSQL（生产环境）**:
```bash
# 创建数据库
createdb zxyk_cloud

# 创建 .env 文件
cat > .env << EOF
DATABASE_URL=postgresql://user:password@localhost/zxyk_cloud
SECRET_KEY=your-secret-key-change-this-in-production
EOF
```

### 步骤 3: 初始化数据库

```bash
# 数据库会在首次启动时自动创建表
# 如果需要手动迁移，使用 alembic
alembic upgrade head
```

### 步骤 4: 启动服务

```bash
# 开发模式（自动重载）
uvicorn app.main:app --host 0.0.0.0 --port 9000 --reload

# 生产模式
uvicorn app.main:app --host 0.0.0.0 --port 9000 --workers 4
```

### 步骤 5: 验证服务

```bash
# 检查健康状态
curl http://localhost:9000/api/cloud/health

# 应返回: {"status":"ok"}
```

## 生产部署

### 使用 Systemd（Linux）

创建服务文件 `/etc/systemd/system/zxyk-cloud.service`:

```ini
[Unit]
Description=智信优控云端平台
After=network.target postgresql.service

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/zxyk-cloud/backend
Environment="PATH=/opt/zxyk-cloud/venv/bin"
ExecStart=/opt/zxyk-cloud/venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 9000 --workers 4
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启动服务:
```bash
sudo systemctl daemon-reload
sudo systemctl enable zxyk-cloud
sudo systemctl start zxyk-cloud
sudo systemctl status zxyk-cloud
```

### 使用 Nginx 反向代理

创建 Nginx 配置 `/etc/nginx/sites-available/zxyk-cloud`:

```nginx
server {
    listen 80;
    server_name cloud.example.com;

    location / {
        proxy_pass http://127.0.0.1:9000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用配置:
```bash
sudo ln -s /etc/nginx/sites-available/zxyk-cloud /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 使用 Docker

创建 `Dockerfile`:

```dockerfile
FROM python:3.9-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 9000

CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "9000"]
```

构建和运行:
```bash
docker build -t zxyk-cloud .
docker run -d -p 9000:9000 --name zxyk-cloud \
  -e DATABASE_URL=postgresql://user:password@db/zxyk_cloud \
  -e SECRET_KEY=your-secret-key \
  zxyk-cloud
```

## 配置本地平台连接云端

### 方法 1: 修改配置文件

编辑本地平台的 `backend/app/config.py`:

```python
CLOUD_API_URL: str = "http://your-cloud-server:9000"  # 修改为云端地址
CLOUD_API_VERIFY_SSL: bool = False  # 如果使用 HTTPS，改为 True
```

### 方法 2: 使用环境变量

```bash
# Windows
set CLOUD_API_URL=http://your-cloud-server:9000

# Linux/macOS
export CLOUD_API_URL=http://your-cloud-server:9000
```

## API 端点说明

### 认证相关

- `POST /api/cloud/auth/login` - 登录
- `POST /api/cloud/auth/register` - 教师注册
- `POST /api/cloud/auth/register/user` - 学生注册（新增）
- `POST /api/cloud/auth/refresh` - 刷新 Token
- `POST /api/cloud/auth/logout` - 登出

### 公开接口（无需认证）

- `GET /api/cloud/public/orgs` - 获取机构列表
- `GET /api/cloud/public/classes?org_id=1` - 获取班级列表

### 管理接口（需要认证）

- `GET /api/cloud/users` - 用户列表
- `GET /api/cloud/tasks` - 任务列表
- `POST /api/cloud/tasks` - 创建任务
- `GET /api/cloud/reports` - 报告列表

## 故障排查

### 问题 1: 本地平台提示"云端服务未配置"

**原因**: `CLOUD_API_URL` 未设置或为空

**解决**:
1. 检查 `backend/app/config.py` 中的 `CLOUD_API_URL`
2. 确保值不为空且格式正确（如 `http://localhost:9000`）

### 问题 2: 本地平台提示"无法连接云端服务"

**原因**: 云端服务未启动或网络不通

**解决**:
1. 检查云端服务是否运行: `curl http://localhost:9000/api/cloud/health`
2. 检查防火墙是否开放 9000 端口
3. 检查本地平台配置的 URL 是否正确

### 问题 3: 注册时提示"机构不存在"或"班级不存在"

**原因**: 数据库中没有机构或班级数据

**解决**:
1. 使用管理员账户登录云端平台
2. 创建机构和班级
3. 或使用 API 创建:
```bash
# 创建机构
curl -X POST http://localhost:9000/api/cloud/organizations \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "大连理工大学"}'

# 创建班级
curl -X POST http://localhost:9000/api/cloud/classes \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "计算机1班", "org_id": 1}'
```

### 问题 4: 数据库连接失败

**原因**: 数据库未启动或连接配置错误

**解决**:
1. 检查 PostgreSQL 是否运行: `sudo systemctl status postgresql`
2. 检查 `.env` 文件中的 `DATABASE_URL` 是否正确
3. 测试数据库连接: `psql -U user -d zxyk_cloud`

## 安全建议

### 生产环境必做

1. **修改默认密码**: 首次登录后立即修改 `super_admin` 密码
2. **使用强密钥**: 修改 `SECRET_KEY` 为随机字符串（至少 32 字符）
3. **启用 HTTPS**: 使用 SSL 证书（Let's Encrypt 免费）
4. **限制 CORS**: 修改 `ALLOWED_ORIGINS` 只允许本地平台域名
5. **定期备份**: 定期备份数据库
6. **更新依赖**: 定期更新 Python 包以修复安全漏洞

### 生成安全密钥

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```
