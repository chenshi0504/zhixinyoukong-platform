# 云端平台开发工作流

## Git 仓库结构

`cloud/` 目录拥有**独立的 `.git`** 仓库，remote 为 `https://github.com/chenshi0504/zhixinyoukong-cloud.git`。

- 父目录（项目根）的 git 仓库**无 remote**，仅本地管理
- 所有 cloud 的 git 操作必须在 `cloud/` 目录下执行

```text
项目根 (.git, 无 remote)
└── cloud/ (.git, origin → GitHub)
    ├── frontend/   # Vue 3 SPA (GitHub Pages)
    ├── backend/    # FastAPI (本地/服务器运行)
    └── ...
```

## 前端部署流程（GitHub Pages）

```text
本地修改 frontend/** → git commit → git push origin main
                                          ↓
                              GitHub Actions 自动触发
                              (.github/workflows/deploy-cloud-frontend.yml)
                                          ↓
                              npm ci → npm run build → 部署到 GitHub Pages
                                          ↓
                              https://chenshi0504.github.io/zhixinyoukong-cloud/
```

**关键点**：

- 触发条件：push 到 main 分支且 `cloud/frontend/**` 有变更
- 构建时 `VITE_API_BASE_URL` 从 GitHub repo variables 读取
- 前端是纯静态 SPA，hash 路由模式，不能本地直接测试 API（除非后端在运行）
- **不需要本地 build**，push 即部署

## 后端部署

后端不在 GitHub Actions 中自动部署。需要：

- 本地开发测试：`cd cloud && python -m uvicorn backend.app.main:app --port 9000`
- 或使用 `start_cloud.bat` 一键启动
- 服务器部署：手动拉取代码 + 重启 uvicorn

## 开发规范

### 提交消息格式

```
feat: 新增教师班级管理功能
fix: 修复统计页面未定义变量
docs: 更新开发日志
style: 调整侧边栏菜单顺序
```

### 开发-部署命令序列

```powershell
# ① 确认在 cloud 目录下
cd d:\chenshi\智信优控_面向车路云一体化的综合交通实验平台\cloud

# ② 查看改动
git status
git diff

# ③ 提交
git add -A
git commit -m "feat: 描述"

# ④ 推送（自动触发 GitHub Pages 部署）
git push origin main

# ⑤ 在 GitHub Actions 页面确认部署成功
# https://github.com/chenshi0504/zhixinyoukong-cloud/actions
```

### 注意事项

- **⚠️ workflow 文件必须在 `cloud/.github/workflows/` 下**，不能放在父仓库的 `.github/` 中。父仓库无 remote，放错位置会导致 GitHub Actions 永远不触发
- **前端改动只改前端**，不要同时改后端（分开提交更安全）
- 如果后端 API 有变更，需先部署后端再部署前端
- `frontend/.env.production` 中的 `VITE_API_BASE_URL` 不要随意改，构建时优先用 GitHub repo variables
- Element Plus 图标需要在组件中按需导入或全局注册

## 前端技术栈速查

| 项 | 值 |
|---|---|
| 框架 | Vue 3 (Composition API, `<script setup>`) |
| UI 库 | Element Plus |
| 图表 | ECharts |
| 状态 | Pinia (`stores/auth.js`) |
| 路由 | Vue Router (Hash 模式) |
| HTTP | Axios (`api/client.js`, 自动 token 刷新) |
| 构建 | Vite |
| 部署 | GitHub Pages (base: `/zhixinyoukong-cloud/`) |
