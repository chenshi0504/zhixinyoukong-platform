# 智信优控 · 云端管理平台 部署指南

## 快速开始（3 步上线）

### 第 1 步：启动后端

在校园 Windows 服务器上：

```powershell
cd cloud\backend
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 9000
```

或直接双击 `cloud\scripts\start_cloud.bat`。

验证：浏览器访问 `http://localhost:9000/api/cloud/health`，应返回 `{"status":"ok"}`。

### 第 2 步：内网穿透

服务器没有公网 IP 时，需要内网穿透工具将 9000 端口暴露到公网。

**使用 cpolar（推荐，国内友好）：**

```powershell
# 1. 下载安装：https://www.cpolar.com/
# 2. 注册并获取 authtoken
cpolar authtoken <你的token>

# 3. 穿透 9000 端口
cpolar http 9000
```

cpolar 会输出公网地址，如 `https://abc123.cpolar.cn`。

**其他选择：**
- **frp**：需要一台有公网 IP 的服务器做中转，地址固定
- **ngrok**：国外服务，`ngrok http 9000`
- **Cloudflare Tunnel**：免费、地址固定，需要域名

### 第 3 步：配置前端

将穿透地址填入 `cloud/frontend/.env.production`：

```env
VITE_API_BASE_URL=https://abc123.cpolar.cn
```

构建并部署到 GitHub Pages：

```bash
cd cloud/frontend
npm install
npm run build

# 部署到 GitHub Pages（需要 Git 推送权限）
cd dist
git init
git add .
git commit -m "deploy"
git push -f git@github.com:chenshi0504/zhixinyoukong-cloud.git main:gh-pages
```

访问 `https://chenshi0504.github.io/zhixinyoukong-cloud/` 即可使用。

## 本地安装包对接云端

学生使用的本地安装包需要配置云端地址才能同步任务和报告。

### 方式 1：打包前配置（推荐）

修改 `backend/.env`：
```env
CLOUD_API_URL=https://abc123.cpolar.cn
CLOUD_API_VERIFY_SSL=true
```

然后重新打包，所有安装包自动连接云端。

### 方式 2：安装后修改

编辑 `安装目录\_internal\backend\.env`：
```env
CLOUD_API_URL=https://abc123.cpolar.cn
```

### 方式 3：环境变量

```powershell
setx CLOUD_API_URL "https://abc123.cpolar.cn"
```

## 配置说明

### 后端配置（cloud/backend/.env）

| 变量 | 说明 | 示例 |
|------|------|------|
| `DATABASE_URL` | 数据库连接 | `sqlite:///./cloud_prod.db` |
| `SECRET_KEY` | JWT 签名密钥 | 64 位随机字符串 |
| `ALLOWED_ORIGINS` | CORS 允许来源 | `https://chenshi0504.github.io,https://abc.cpolar.cn` |
| `CLOUD_APP_PORT` | 监听端口 | `9000` |
| `UPLOAD_DIR` | 文件上传目录 | `./uploads` |
| `DEBUG` | 调试模式 | `false` |

### 前端配置（cloud/frontend/.env.production）

| 变量 | 说明 | 示例 |
|------|------|------|
| `VITE_API_BASE_URL` | 后端 API 地址 | `https://abc123.cpolar.cn` |

## 注意事项

1. **穿透地址变更**：免费版 cpolar 每次重启地址会变，需同步更新：
   - `cloud/backend/.env` → `ALLOWED_ORIGINS`
   - `cloud/frontend/.env.production` → `VITE_API_BASE_URL`（需重新 build）
   - 本地安装包 `CLOUD_API_URL`
   
2. **数据备份**：定期备份 `cloud_prod.db` 和 `uploads/` 目录

3. **Windows 服务化**：使用 NSSM 实现开机自启：
   ```powershell
   nssm install CloudAPI "python" "-m uvicorn app.main:app --host 0.0.0.0 --port 9000"
   nssm set CloudAPI AppDirectory "D:\path\to\cloud\backend"
   nssm start CloudAPI
   ```
