## 一句话定位

云端管理平台是智信优控产品的"管理中枢"，负责跨客户端的用户授权、教学管理和数据同步，**不运行任何算法**，服务器配置极低（2核4G即可）。

## 技术栈说明

云端管理平台是一个独立的Web服务，与本地客户端通过 **HTTP API + JSON** 通信，两边的实现语言完全解耦。后端可以用任何成熟的Web框架（Go、Node.js、Python、Java等），根据团队实际情况选择。文档中描述的是通用的架构模式和接口契约，不绑定特定语言。
