平台组成

三部分，各自负责一件事

本地平台做实验，云端平台管教学，发布平台负责跨电脑访问和服务器运行。

01 LOCAL

本地实验平台

学生完成数据、预测、优化、控制和仿真实验，提交参数后由服务器执行算法并返回结果。

  • 交通流重构与预测
  • 信号优化、路径诱导、车速控制
  • 数据融合、SUMO/CARLA 仿真验证
02 CLOUD

云端管理平台

管理员和教师管理教学组织、账号授权、任务发布、报告批阅和运行统计。

  • 机构、教师、班级管理
  • 任务发布与提交记录
  • 报告查看、批阅和反馈
03 RELEASE

发布部署平台

面向机房、演示和外部电脑访问，把前端页面、后端 API、算法服务和资料下载统一部署在服务器。

  • 通过服务器 IP 访问平台
  • 算法在服务器端执行
  • 资料按版本统一下载
使用流程

一条清晰的教学实验链路

教师先建任务，学生做实验，服务器跑算法，最后回到云端查看报告。

1
教师建课与发任务

在云端管理平台维护班级、学生和实验任务。

2
学生配置实验

进入本地实验平台，选择模块、数据和算法参数。

3
服务器执行算法

后端统一运行仿真和算法，页面展示图表与指标。

4
报告回收与批阅

教师查看提交记录、下载报告并给出反馈。

实验能力

围绕车路云实验主线组织模块

从数据采集、状态估计到协同控制和虚实仿真，支撑课堂演示与学生实验。

多源数据采集与融合

融合路侧、车辆、检测器和仿真数据，支持数据处理与可视化。

交通流重构

基于路网与检测数据完成交通状态估计和结果分析。

交通流预测

支持历史数据建模、预测结果展示和性能指标对比。

三层级协同优化控制

围绕宏观诱导、信号控制和车辆控制开展协同实验。

交通信号优化

提供交叉口配时、优化算法对比和报告导出能力。

路径诱导

支持路径选择、诱导策略和运行效果对比。

车规级智能车辆开发

对接车速控制、小车系统和车路协同控制实验内容。

虚实结合仿真

通过 SUMO/CARLA 等工具完成场景构建、算法测试和结果回放。
