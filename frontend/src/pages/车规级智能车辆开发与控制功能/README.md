# 车规级智能小车控制功能教学模块

## 模块概述

车规级智能小车控制功能教学模块是一个静态前端教学界面，用于演示和教授智能小车控制技术的基本概念。该模块通过模拟数据展示智能小车的控制参数配置、实时状态监控和性能指标分析。

## 功能特性

### 控制参数配置
- **速度控制**：目标速度设置（0-100 km/h）、加速度参数调节（1-10 m/s²）
- **方向控制**：转向角度设置（-45°到45°）、转向速度调节（1-20 °/s）
- **传感器设置**：激光雷达和摄像头启用/禁用开关
- **障碍物设置**：障碍物数量选择（0-3个）、类型选择（静态/动态）

### 仿真控制
- **开始/停止仿真**：一键启动和停止仿真过程
- **参数重置**：快速恢复所有参数为默认值
- **状态监控**：实时显示仿真运行状态

### 数据展示
- **实时数据监控**：当前速度、转向角度、行驶距离、运行时间
- **传感器状态**：激光雷达和摄像头工作状态显示
- **性能指标**：控制精度、响应时间、能耗效率
- **仿真视图**：预留可视化区域，用于后续集成

## 使用方法

### 直接预览
1. 使用Edge浏览器打开 `vehicle_control.html` 文件
2. 页面将自动加载并显示完整的教学界面

### 集成到主平台
1. 将整个模块文件夹放置在平台相应目录下
2. 在主平台的导航系统中添加对应的链接
3. 确保相对路径引用正确

## 操作指南

### 基本操作流程
1. **参数配置**：在左侧面板调整各项控制参数
2. **启动仿真**：点击"开始仿真"按钮启动模拟过程
3. **观察结果**：在右侧面板查看实时数据和性能指标
4. **参数调整**：停止仿真后可重新调整参数
5. **重置参数**：使用"重置参数"按钮恢复默认设置

### 参数说明
- **目标速度**：设置小车期望达到的行驶速度
- **加速度**：控制小车加速和减速的快慢
- **转向角度**：设置小车的转向方向和幅度
- **转向速度**：控制转向动作的执行速度
- **传感器开关**：启用或禁用相应的感知设备
- **障碍物设置**：模拟环境中的障碍物情况

- **理论教学**：智能小车控制原理讲解
