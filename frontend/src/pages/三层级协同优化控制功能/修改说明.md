# 三层级协同优化控制功能 - 界面修改说明

## 修改日期
2025-12-02

## 修改内容

### 1. 按钮位置调整
**修改前：** 操作按钮（数据保存、后端检测、开始优化、停止、重置状态）位于右侧展示区域

**修改后：** 所有操作按钮移至左侧配置面板，位于"转向比数据"下方

**优点：**
- 更符合操作流程逻辑
- 左侧集中配置和操作，右侧专注展示结果
- 界面布局更清晰

### 2. 结果展示逻辑优化
**修改前：** 页面加载时自动展示文件和图片（如果后端已连接）

**修改后：** 
- 初始状态：图片和文件区域显示占位提示
- 点击"处理输出文件"按钮后，才调用后端API生成并展示结果
- 逐步展示：先处理 → 再展示图片 → 再展示文件列表

**优点：**
- 用户主动触发，流程更清晰
- 避免页面加载时的混乱
- 符合"按需加载"的交互逻辑

### 3. 重置状态功能完善
**新增功能：**
- 重置所有文件输入
- 清空文件名显示
- 重置所有步骤按钮样式
- 隐藏所有结果图片和文件
- 重置优化结果数据（延误、时间、油耗、通行量）
- 清空控制台输出（保留系统消息）
- 恢复状态为"就绪"

**使用方式：**
点击左侧"🔄 重置状态"按钮

### 4. 图片查看功能增强
**新增功能：**
- 所有结果图片都可以点击查看大图
- 每张图片右上角有"🔍 查看大图"按钮
- 路网拓扑图也可以点击查看大图

### 5. 文件下载功能
**新增功能：**
- 数据文件列表中每个文件都有"下载"按钮
- 点击后在新标签页打开文件

## 文件修改清单

### HTML文件 (three_level_control.html)
1. 将操作按钮区域从右侧移至左侧
2. 在左侧"转向比数据"下方添加"操作控制"区域
3. 删除右侧原有的操作控制区域
4. 保留右侧的状态栏

### JavaScript文件 (three_level_control.js)
1. 修改初始化逻辑，调用 `hideResultsAndFiles()` 隐藏结果
2. 新增 `hideResultsAndFiles()` 函数 - 隐藏所有结果和文件
3. 新增 `resetConfiguration()` 函数 - 完整的重置功能
4. 新增 `processOutputFiles()` 函数 - 处理输出文件
5. 新增 `loadOutputFiles()` 函数 - 加载输出文件列表
6. 新增 `displayOutputFiles()` 函数 - 显示图片和文件
7. 新增 `loadNetworkTopology()` 函数 - 加载路网拓扑图

## 使用流程

### 正常使用流程：
1. 上传配置文件（仿真配置、OD需求、决策变量等）
2. 点击"💾 数据保存"保存配置
3. 点击"🔍 后端检测"检查后端连接
4. 点击"▶️ 开始优化"运行优化
5. 优化完成后，点击"处理输出文件"生成结果图表
6. 查看结果图片和下载数据文件

### 重置流程：
1. 点击"🔄 重置状态"
2. 确认重置
3. 所有配置和结果被清空，回到初始状态

## 注意事项
1. 优化运行中无法重置，需先停止优化
2. 处理输出文件需要后端服务支持相应API
3. 图片路径需要后端API返回正确的路径
4. 所有按钮都有图标，更直观易用
