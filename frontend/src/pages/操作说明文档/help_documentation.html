    平台概述

    平台简介

    "智信优控：面向车路云一体化的综合交通实验平台"是一个集教学管理、实验操作、数据分析于一体的综合性教学实验平台。平台以"数据-仿真-控制-验证"为主线，按照"数据采集-融合-重构-预测-优化-控制-验证"的完整链条进行构建，为师生提供虚实结合的仿真实验环境。

    五大核心功能模块

    • 多源数据采集与融合模块 - 支持视频、雷达、线圈等多种数据源的实时采集，集成YOLOv8+DeepSort车辆检测跟踪算法，基于贝叶斯融合算法进行多源数据融合
    • 交通流重构与预测模块 - 基于DTALite动态交通分配平台实现交通流重构，集成线性回归、随机森林、LSTM、GRU等多种预测算法
    • 三层级协同优化控制模块 - 上层信号优化（Webster/HCM/BO/TuRBO/MPC-TuRBO）、中层路径诱导（Dijkstra/A*/Floyd）、下层车速控制（PID/MPC/ACC）
    • 虚实结合仿真模块 - 基于CARLA仿真平台构建三维交通场景，基于SUMO仿真引擎进行算法测试验证，支持硬件在环测试
    • 实验教学管理模块 - 教学任务发布、学生信息管理、实验报告在线评阅、操作说明文档

    实验模块说明

    多源数据采集功能

    多源数据采集功能用于从视频、雷达、线圈等多种数据源采集交通流数据。该功能基于YOLOv8+DeepSort算法实现车辆检测与跟踪，能够实时提取车辆位置、速度、车型等信息，为后续的数据融合和交通分析提供基础数据支撑。

    操作步骤

    1. 在主界面点击"多源数据采集与融合模块"卡片展开子功能列表
    2. 选择"多源数据采集功能"，进入数据采集界面
    3. 在数据源配置区域选择数据源类型（视频/雷达/线圈），配置数据源参数
    4. 点击"开始采集"按钮，系统基于YOLOv8+DeepSort算法进行车辆检测跟踪
    5. 在数据展示区域实时查看采集到的交通流数据
    6. 点击"停止采集"结束采集，点击"导出数据"将数据导出为CSV文件

    数据要求

    • 视频格式：以.mp4为主，兼容.avi、.mov、.mkv等格式
    • 分辨率：建议不低于720P（1280x720），推荐1080P
    • 帧率：建议不低于25fps，以保证车辆跟踪的连续性
    • 拍摄角度：建议采用俯视或斜俯视角度，避免车辆遮挡

    输出说明

    系统从视频中自动提取车辆轨迹信息，按15分钟间隔统计各类车辆流量（小汽车、公交车、卡车），输出包含时间间隔、各车型数量和总流量的统计表。算法统计误差大部分在15%以内。

    多源数据融合功能

    多源数据融合功能采用贝叶斯融合算法，将来自不同数据源（视频检测结果与点云数据）的交通数据进行时空对齐和信息融合，提高数据的准确性和完整性。

    操作步骤

    1. 在"多源数据采集与融合模块"中选择"多源数据融合功能"
    2. 选择需要融合的数据源（可多选），上传各数据源的数据文件
    3. 设置融合参数（时间窗口、空间阈值、置信度权重）
    4. 点击"开始融合"执行贝叶斯融合算法
    5. 在结果展示区域查看融合结果，包括信息熵、融合精度、数据完整性等指标
    6. 点击"导出结果"将融合数据导出

    输入数据格式

    • YOLO检测结果（JSON）：包含class_name（类别）、mean_conf（置信度）、var_conf（方差）、count（数量）、mean_bbox（边界框）
    • 点云熵数据（JSON）：包含entropy（熵值，越低越确定）、count（目标数量）

    融合输出

    贝叶斯融合后输出JSON文件，包含yolo_mean_conf（YOLO置信度）、pc_entropy（点云熵值）、fused_prob（融合概率）。融合概率综合了视频和点云两种数据源的信息，提供更可靠的目标检测结果。

    交通流重构功能

    交通流重构功能基于DTALite动态交通分配模型，利用有限的观测数据估计完整的OD（起讫点）矩阵。通过迭代优化算法使重构的交通流与实际观测数据相匹配，为交通规划和管理提供决策支持。

    操作步骤

    1. 在主界面点击"交通流重构与预测模块"卡片展开子功能列表
    2. 选择"交通流重构功能"，进入交通流重构界面
    3. 上传路网文件（.net.xml）和观测数据文件（.csv）
    4. 设置重构参数（时间段、迭代次数、收敛阈值）
    5. 点击"开始重构"执行基于DTALite的OD矩阵估计算法
    6. 查看重构结果：OD矩阵热力图、路段流量对比、误差分析
    7. 点击"导出OD矩阵"或"生成报告"保存结果

    输入数据

    • 路段数据（input_link.csv）：路段编号、起终点节点、长度、车道数、限速、通行能力
    • 节点数据（input_node.csv）：节点编号、坐标、节点类型
    • 观测数据（sensor_count.csv）：路段编号、观测流量、时间段

    输出结果

    输出OD矩阵（output_ODMOE.csv），包含起终点小区编号、出行量、出行时间和出行距离。同时生成路段流量时序变化图和误差分布直方图。

    交通流预测功能

    交通流预测功能提供多种预测模型，包括线性回归、随机森林、LSTM和GRU等深度学习模型。用户可根据数据特点选择合适的模型，实现短期和中期交通流量预测。

    操作步骤

    1. 在"交通流重构与预测模块"中选择"交通流预测功能"
    2. 上传历史交通流数据文件（CSV格式）
    3. 选择预测模型（线性回归/随机森林/LSTM/GRU）
    4. 设置预测参数（历史时长、预测时长、预测间隔）
    5. 点击"开始预测"执行预测算法
    6. 查看预测曲线图和误差指标（MAE、RMSE、MAPE）

    可选预测模型

    • 线性回归 - 适用于线性趋势明显的数据，计算速度快
    • 随机森林 - 适用于非线性关系的数据，泛化能力好
    • LSTM（长短期记忆网络） - 适用于时序数据，能捕捉长期依赖关系
    • GRU（门控循环单元） - 与LSTM类似但结构更简洁，训练速度更快

    数据要求

    历史交通流数据采用CSV格式，采集间隔为15分钟，建议至少包含一周以上的历史数据。数据字段包括日期、时间、日期类型、总流量、各车型流量和平均速度。

    交通信号优化功能（上层控制）

    交通信号优化功能是三层级协同优化控制的上层控制，提供多种信号配时优化算法，通过优化交叉口信号配时方案减少车辆延误，提高路网通行效率。

    操作步骤

    1. 在主界面点击"三层级协同优化控制模块"卡片展开子功能列表
    2. 选择"上层-交通信号优化功能"，进入信号优化界面
    3. 选择优化算法（Webster/HCM/BO/TuRBO/GA/MPC-TuRBO）
    4. 上传路网文件、车流文件和初始配时文件
    5. 设置优化参数（优化目标、优化维度、迭代次数、批处理大小）
    6. 点击"开始优化"执行信号优化算法
    7. 优化过程中实时查看优化进度和目标函数值变化曲线
    8. 优化完成后查看TuRBO迭代时间、SUMO运行总时间、目标函数值及配时方案文件路径
    9. 点击"导出配时方案"保存结果，或点击"应用到仿真"进行验证

    可选优化算法

    • Webster算法 - 经典信号配时方法，基于饱和流率和交通量计算最佳周期和绿信比
    • HCM算法 - 基于美国《道路通行能力手册》的信号配时方法
    • 贝叶斯优化（BO） - 基于高斯过程代理模型的黑盒优化算法
    • TuRBO - 信赖域贝叶斯优化算法，适用于高维优化问题
    • 遗传算法（GA） - 基于自然选择的进化优化算法
    • MPC-TuRBO - 结合模型预测控制与TuRBO的协同优化算法，可实现滚动优化

    输入数据

    • 路网数据（大网络路网.xlsx）：起终点、车道数、通行能力、速度、长度、自由流时间
    • OD需求数据（大路网需求.xlsx）：OD矩阵形式的出行需求
    • 决策变量（决策变量.xlsx）：交叉口编号、相位编号、绿灯时长上下界
    • 相位配置（相位.xlsx）：交叉口相位数量、黄灯时长、全红时长
    • 转向比（转向比.xlsx）：各进口道左转和直行比例
    • 先验数据（先验.csv，可选）：历史优化结果，用于加速TuRBO收敛

    优化效果

    以实际路网测试为例，MPC-TuRBO优化后车均延误从96.84秒降至83.46秒，优化效果达13.82%。

    路径诱导功能（中层控制）

    路径诱导功能是三层级协同优化控制的中层控制，提供多种路径规划算法。根据实时交通状态为车辆规划最优行驶路径，实现交通流的合理分配，缓解局部拥堵。

    操作步骤

    1. 在"三层级协同优化控制模块"中选择"中层-路径诱导功能"
    2. 上传路网文件和实时交通状态文件
    3. 在地图上选择起点和终点
    4. 选择优化目标（最短时间/最短距离/最少拥堵）
    5. 选择路径算法（Dijkstra/A*/Floyd/动态规划）
    6. 点击"规划路径"执行路径规划算法
    7. 在地图上查看最优路径和备选路径，显示路径信息（总距离、预计时间、途经路段）
    8. 点击"导出路径"保存路径信息，或点击"发送诱导信息"将指令发送给车辆

    可选路径算法

    • Dijkstra算法 - 经典最短路径算法，保证找到全局最优解
    • A*算法 - 启发式搜索算法，搜索效率高于Dijkstra
    • Floyd算法 - 多源最短路径算法，适用于计算所有节点对之间的最短路径
    • 动态规划 - 适用于多阶段决策的路径优化问题

    车速控制功能（下层控制）

    车速控制功能是三层级协同优化控制的下层控制，提供PID、MPC和ACC自适应巡航控制等算法。通过精确控制车辆速度实现平稳行驶和节能驾驶，配合信号优化和路径诱导实现协同控制。

    操作步骤

    1. 在"三层级协同优化控制模块"中选择"下层-车速控制功能"
    2. 选择控制算法（PID/MPC/ACC自适应巡航控制）
    3. 设置控制参数（目标速度、控制周期、PID参数、约束条件）
    4. 选择控制车辆（单车/车队）
    5. 点击"开始控制"执行车速控制算法
    6. 在实时监控区域查看速度曲线、控制输入、跟踪误差统计
    7. 点击"停止控制"结束控制，点击"导出数据"保存控制数据

    可选控制算法

    • PID控制 - 经典比例-积分-微分控制器，参数调节简单，响应速度快
    • MPC控制（模型预测控制） - 基于车辆动力学模型的预测控制，考虑未来多步优化
    • ACC自适应巡航控制 - 根据前车状态自动调节车速，保持安全跟车距离

    三层级协同优化控制功能

    三层级协同优化控制功能实现上层信号优化、中层路径诱导、下层车速控制的协同联动。基于MPC-TuRBO算法，通过层级间的信息交互和协同决策，实现全局最优的交通控制效果。

    操作步骤

    1. 在"三层级协同优化控制模块"中选择"三层级协同优化控制功能"
    2. 分别配置上层（信号优化）、中层（路径诱导）、下层（车速控制）的算法和参数
    3. 设置协同参数（信息交互周期、协同权重、全局优化目标）
    4. 上传路网文件和交通需求文件
    5. 点击"开始协同控制"执行基于MPC-TuRBO的三层级协同优化算法
    6. 在实时监控区域分别查看三层控制效果：上层显示信号配时方案和优化效果；中层显示路径诱导方案和路径分布；下层显示车速控制效果和车辆轨迹；全局显示整体交通性能指标
    7. 在协同效果分析区域查看协同前后对比、层级贡献分析、协同效率评估
    8. 点击"生成报告"生成详细的协同控制分析报告

    虚实结合仿真场景构建功能

    虚实结合仿真场景构建功能基于CARLA仿真平台，支持创建多样化的交通仿真场景。用户可配置道路网络、交通流、天气条件、传感器等参数，构建逼真的虚拟交通环境。

    操作步骤

    1. 在主界面点击"面向车路协同的虚实结合仿真模块"卡片展开子功能列表
    2. 选择"虚实结合仿真场景构建功能"，进入场景构建界面
    3. 基于CARLA仿真平台选择场景类型（预设场景/自定义场景）
    4. 配置场景参数：道路网络、交通流、天气条件（晴天/雨天/雾天）、传感器配置（摄像头/激光雷达/毫米波雷达）
    5. 添加交通参与者（车辆、行人、交通设施）
    6. 点击"预览场景"在3D视图中查看场景效果
    7. 调整视角和参数直至满意
    8. 点击"保存场景"保存配置，点击"启动仿真"开始运行CARLA仿真场景

    车规级智能车辆开发与控制功能

    车规级智能车辆开发与控制功能支持智能车辆的开发、调试和控制。提供车辆动力学模型配置、传感器配置、控制算法选择等功能，并保留与真实智能小车对接的接口，支持硬件在环测试。

    操作步骤

    1. 在"面向车路协同的虚实结合仿真模块"中选择"车规级智能车辆开发与控制功能"
    2. 选择车辆模型，配置车辆参数（动力学参数、传感器配置、控制参数）
    3. 设置控制模式（手动/自动/混合），设置起点和终点
    4. 点击"连接车辆"建立与仿真车辆（或真实智能小车）的通信连接
    5. 连接成功后点击"开始仿真"，车辆按照设定的控制算法行驶
    6. 在实时监控区域查看：动态俯视图（车辆位置和轨迹）、车辆状态信息（速度、加速度、方向）、雷达扫描建图、通信质量（信号强度、延迟、丢包率）
    7. 点击"生成报告"生成实验报告

    硬件在环测试

    该功能保留与真实智能小车对接的接口，支持硬件在环测试。可实现智能小车的地图场景自主扫描与构建、寻迹与避障等功能验证。

    虚实结合仿真场景算法测试功能

    虚实结合仿真场景算法测试功能基于SUMO微观交通仿真平台，支持对信号优化、路径诱导、车速控制等算法进行仿真测试和性能评估。

    操作步骤

    1. 在"面向车路协同的虚实结合仿真模块"中选择"虚实结合仿真场景算法测试功能"
    2. 选择仿真场景（预设场景/自定义场景）
    3. 上传仿真配置文件：路网文件（.net.xml）、车流文件（.rou.xml）、网络配置文件（.sumocfg）
    4. 设置仿真参数（仿真时长、时间步长、随机种子）
    5. 选择测试算法（信号优化/路径诱导/车速控制）
    6. 点击"开始仿真"启动SUMO仿真
    7. 仿真过程中实时查看仿真进度、实时指标、车辆动画
    8. 仿真完成后查看时间序列图、行程分析图、统计数据（平均延误、平均速度、通过车辆数等）
    9. 点击"分析结果"生成详细分析图表，点击"下载报告"下载DOCX格式的仿真报告

    SUMO仿真数据文件

    • 路网文件（.net.xml） - 定义道路网络结构（必需）
    • 车流文件（.rou.xml） - 定义车辆出行需求（必需）
    • 配置文件（.sumocfg） - 定义仿真参数（必需）
    • 附加文件（.add.xml） - 定义检测器等附加设施（可选）
    • OD需求（.od/.xlsx） - 定义OD矩阵（可选）

    常见问题

    平台无法启动怎么办？

    请按以下步骤排查：

    1. 确认已安装Python 3.8+环境
    2. 确认已安装所有依赖包（运行 pip install -r requirements.txt）
    3. 检查端口8000是否被占用
    4. 确认服务器端主平台服务正在运行
    5. 查看服务器日志或联系管理员

    登录后页面显示空白或报错？

    • 清除浏览器缓存后重新登录
    • 确认后端服务正在运行（登录页底部状态指示灯为绿色）
    • 使用Chrome 90+或Edge 90+浏览器
    • 检查浏览器控制台（F12）是否有错误信息

    上传数据文件失败？

    • 确认文件格式正确（CSV、JSON、XML等，参考各模块数据要求）
    • 确认文件大小未超过限制
    • 确认文件编码为UTF-8
    • 检查文件内容是否包含必需的字段和列

    算法运行时间过长？

    部分算法计算量较大，建议：

    • 先使用小规模数据进行测试
    • 适当减少迭代次数或仿真时长
    • 确保计算机满足最低配置要求（Intel i5+，8GB内存）
    • 关闭其他占用资源的程序

    学生看不到某些功能模块？

    这是正常的权限设置。学生可以访问五大实验模块的全部功能，但以下功能仅限教师和管理员使用：

    • 学生信息管理（用户信息管理）
    • 实验报告管理

    SUMO或CARLA仿真无法启动？

    • SUMO：需安装SUMO 1.12.0+，并配置SUMO_HOME环境变量
    • CARLA：需安装CARLA 0.9.13+（可选），并确保GPU驱动正常
    • 确认仿真配置文件格式正确且路径无中文字符

    如何导出实验结果？

    • 数据类结果：点击"导出数据"按钮，导出为CSV格式
    • 分析报告：点击"生成报告"或"下载报告"，导出为DOCX格式
    • 优化方案：点击"导出配时方案"或"导出路径"保存结果
