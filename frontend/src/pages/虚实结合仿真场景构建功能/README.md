# 基于Carla的场景构建功能教学模块

## 功能概述
这是一个用于教学的Carla场景构建演示模块，学生可以通过选择预设场景、调整参数、运行仿真来理解Carla仿真平台的场景构建原理和车路协同仿真的基本概念。

## 文件结构
- `carla_scene_builder.html` - 主页面文件
- `carla_scene_builder.css` - 样式文件
- `carla_scene_builder.js` - 交互脚本文件

## 使用方法
1. 在Edge浏览器中打开 `carla_scene_builder.html`
2. 选择预设场景：
   - 典型场景1：基础城市道路场景
   - 典型场景2：高速公路场景
3. 调整场景参数：
   - 天气条件：晴天、雨天、雾天
   - 交通密度：0-100%（滑块控制）
4. 点击"应用自定义设置"确认参数
5. 观察右侧场景构建区域的效果展示
6. 点击"开始仿真"运行场景仿真
7. 查看仿真结果和教学步骤引导

## 功能特性
- ✅ 预设场景选择（城市道路、高速公路）
- ✅ 场景参数配置（天气、交通密度）
- ✅ 场景元素展示按钮（车辆、行人、障碍物、道路、信号灯）
- ✅ 实时场景信息显示
- ✅ 仿真控制和状态管理
- ✅ 教学步骤引导系统
- ✅ 一键重置功能
- ✅ 响应式设计
- ✅ 用户友好的消息提示

## 界面布局
- **左侧区域**（30%）：场景配置面板
  - 预设场景选择区域
  - 场景参数配置区域
  - 场景元素展示按钮区域
- **右侧区域**（70%）：场景构建可视化区域
  - 场景信息展示
  - 场景预览区域
- **底部区域**：仿真控制和教学步骤
  - 仿真控制按钮
  - 教学步骤引导

## 教学步骤
1. **选择预设场景** - 从城市道路或高速公路场景中选择
2. **调整场景参数** - 设置天气条件和交通密度
3. **运行仿真** - 启动Carla场景仿真
4. **分析结果** - 观察仿真效果和结果分析

## 技术规格
- 分辨率优化：1920×1080
- 浏览器兼容：Edge浏览器
- 响应式设计：支持移动端适配
- 交互方式：点击选择、滑块调节、按钮控制

## 教学价值
- 帮助学生理解Carla仿真平台的基本概念
- 通过场景选择学习不同交通环境的特点
- 通过参数调节理解环境因素对仿真的影响
- 提供直观的场景构建流程和步骤引导
- 模拟车路协同仿真的基础操作流程
