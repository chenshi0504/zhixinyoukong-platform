算法讲解

YOLO11 + BoTSORT 车辆检测跟踪算法

基于深度学习的实时车辆检测与多目标跟踪方法，能够识别视频中的多类车辆目标，并进行跨帧跟踪和分时段流量统计，为交通数据采集提供自动化解决方案。

核心步骤：
1. 加载视频文件和YOLO11预训练模型（COCO数据集）
2. 逐帧检测车辆目标（类型+位置+置信度）
3. BoTSORT算法跨帧跟踪并分配唯一ID
4. 每15分钟输出分类流量统计结果

算法组成：
• YOLO11：基于PyTorch的最新单阶段目标检测器，C3k2模块，精度速度均衡最优
• BoTSORT：ultralytics内置跟踪器，卡尔曼滤波 + Re-ID特征 + 运动补偿
• 流量统计：基于跟踪ID去重，按15分钟时段汇总分类计数

检测目标：小汽车 (Car) · 公交车 (Bus) · 卡车 (Truck)

参数配置：IOU阈值 0.45 · 置信度阈值 0.50 · NMS重叠阈值 1.0
