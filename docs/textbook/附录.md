## 附录A 平台操作快速指南

### A.1 系统启动与登录

**系统环境要求**

在使用智信优控平台之前，请确保计算机满足以下基本要求：
- 操作系统：Windows 10/11 或 Linux（Ubuntu 18.04+）
- 内存：8GB以上（推荐16GB）
- 显卡：支持OpenGL 3.3+（部分功能需要独立显卡）
- 浏览器：Chrome 90+、Firefox 88+、Edge 90+
- 网络：能够访问平台服务器

**启动后端服务**

1. 打开命令行终端
2. 进入平台后端目录：`cd 2_API_management`。
3. 启动API服务：运行 `启动所有后端服务.bat`（Windows）。
4. 等待服务启动完成，终端显示"服务已启动"。

**访问平台前端**

1. 打开浏览器
2. 访问平台地址：`http://localhost:8080` 或服务器地址。
3. 进入登录页面

**用户登录**

1. 在登录页面输入用户名和密码
2. 选择用户角色（教师/学生）
3. 点击"登录"按钮
4. 登录成功后进入主界面

## 附录B 常见问题解答

### B.1 环境配置问题

**Q1：后端服务无法启动，提示端口被占用**

A：这通常是因为之前的服务未正常关闭。解决方法：
1. 打开任务管理器，结束相关的Python进程。
2. 或者修改配置文件中的端口号
3. 重新启动服务

**Q2：浏览器无法访问平台页面**

A：请检查以下几点：
1. 确认后端服务已正常启动
2. 检查浏览器地址是否正确
3. 检查防火墙设置，确保端口未被阻止
4. 尝试清除浏览器缓存后重新访问

**Q3：CARLA仿真无法启动**

A：CARLA对显卡有一定要求，请检查：
1. 显卡驱动是否为最新版本
2. 显卡是否支持OpenGL 3.3+
3. 系统内存是否充足（建议16GB以上）。
4. 是否有其他程序占用大量显存

**Q4：SUMO仿真报错**

A：常见原因和解决方法：
1. 路网文件格式错误：检查.net.xml文件的格式。
2. 需求文件错误：检查.rou.xml文件中的车辆路径定义。
3. 配置文件路径错误：确保.sumocfg中的文件路径正确。

### B.2 功能使用问题

**Q5：车辆检测结果不准确**

A：可能的原因和改进方法：
1. 视频质量较差：尝试使用更高分辨率的视频。
2. 光照条件不佳：调整检测参数中的置信度阈值。
3. 车辆遮挡严重：这是检测算法的固有局限，可尝试多角度检测。

**Q6：信号优化收敛速度慢**

A：可以尝试以下方法：
1. 减少决策变量的数量（如固定部分相位的绿灯时间）。
2. 缩小参数搜索范围
3. 增加初始采样点数量
4. 使用更高效的优化算法（如TuRBO）。

**Q7：路径规划结果不合理**

A：请检查：
1. 路网数据是否完整（是否存在断头路）
2. 路段权重设置是否合理
3. 起终点位置是否在路网范围内
4. 是否存在单向道路导致的不可达

**Q8：三层级协同优化运行时间过长**

A：协同优化计算量较大，可以尝试：
1. 减小路网规模（选择子区域进行测试）
2. 降低仿真精度（增大时间步长）
3. 减少优化迭代次数
4. 使用更高性能的计算机

### B.3 故障排查方法

**日志查看**

平台运行日志保存在`logs`目录下，可以通过查看日志定位问题：
- `api.log`：API服务日志
- `sumo.log`：SUMO仿真日志
- `carla.log`：CARLA仿真日志

**常见错误代码**

| 错误代码 | 含义 | 解决方法 |
|----------|------|----------|
| E001 | 数据库连接失败 | 检查数据库服务是否启动 |
| E002 | 文件不存在 | 检查文件路径是否正确 |
| E003 | 参数格式错误 | 检查输入参数的格式 |
| E004 | 仿真超时 | 增加超时时间或简化场景 |
| E005 | 内存不足 | 关闭其他程序或增加内存 |

**问题反馈**

如果遇到无法解决的问题，请通过以下方式反馈：
1. 记录问题的详细描述和复现步骤
2. 收集相关的日志文件
3. 截取错误提示的截图
4. 联系技术支持人员
