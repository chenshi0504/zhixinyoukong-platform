一、登录系统

  1. 启动软件（双击桌面快捷方式或 智信优控.exe）
  2. 等待加载完成，自动跳转到登录页面
  3. 输入学生账号和密码，角色选择"学生"
  4. 点击"登录系统"

默认学生账号：student / 123456（首次登录后请修改密码）

如果账号由教师批量导入，请使用教师提供的用户名和初始密码。

二、学生首页概览

登录后进入学生首页，左侧导航栏包含以下功能：

功能区域 说明
实验功能模块 10个交通实验功能
教学任务 查看教师发布的实验任务
实验报告 提交实验报告
算法设计 编写和提交自定义算法脚本
操作说明 平台使用帮助

三、查看教学任务

  1. 进入"教学任务"页面
  2. 查看教师发布的所有任务列表
  3. 每个任务显示：标题、描述、截止日期、关联实验模块
  4. 点击任务可查看详细要求
  5. 根据任务要求完成对应的实验操作

四、实验操作流程

4.1 通用实验流程

  1. 查看教学任务中的实验要求
  2. 进入对应的实验功能模块
  3. 按照实验要求配置参数
  4. 运行实验，等待结果
  5. 查看和分析实验结果
  6. 撰写并提交实验报告

4.2 交通信号优化实验（示例）

  1. 进入"交通信号优化功能"页面
  2. 选择路网场景（或上传自定义路网）
  3. 选择优化算法（如DQN、PSO等）
  4. 配置仿真参数（仿真时长、车流量等）
  5. 点击"开始优化"
  6. 等待SUMO仿真运行完成
  7. 查看优化结果：信号配时方案、延误指标、通行效率等
  8. 导出结果数据用于报告撰写

4.3 路径诱导实验（示例）

  1. 进入"路径诱导功能"页面
  2. 选择路网和OD对
  3. 选择路径算法（Dijkstra/SSP/A*）
  4. 运行路径计算
  5. 查看最优路径可视化结果和路径指标

4.4 车速控制实验（示例）

  1. 进入"车速控制功能"页面
  2. 选择控制模型（IDM/ACC/CACC/PID）
  3. 配置车辆参数和道路场景
  4. 运行仿真
  5. 查看速度曲线、车头时距等指标

五、提交实验报告

5.1 撰写报告

  1. 进入"实验报告"页面
  2. 点击"提交报告"
  3. 选择关联的教学任务
  4. 填写报告内容：
  • 实验目的
  • 实验步骤
  • 实验数据和结果截图
  • 结果分析
  1. 上传附件（可选，如数据文件、截图等）
  2. 点击"提交"

5.2 查看评阅结果

  • 报告提交后，等待教师评阅
  • 评阅完成后可查看：评分、教师评语
  • 报告状态：草稿 → 已提交 → 已评阅

六、算法设计与提交

6.1 算法脚本编辑

  1. 进入"算法设计"功能
  2. 选择算法模板（如信号优化模板、路径规划模板）
  3. 在代码编辑器中编写Python算法脚本
  4. 算法模板提供了基础框架，学生需要实现核心逻辑

6.2 算法测试

  1. 编写完成后点击"运行测试"
  2. 系统在沙箱环境中执行算法
  3. 查看运行结果和输出日志
  4. 如有错误，根据错误信息修改代码

6.3 提交算法

  1. 测试通过后点击"提交算法"
  2. 算法将关联到对应的教学任务
  3. 教师可查看和评阅提交的算法

八、常见问题

Q: 看不到教师发布的任务？ A: 确认已登录正确的学生账号。如果使用云端同步，需要联网才能接收最新任务。

Q: 实验运行失败？ A: 检查是否已安装所需的外部软件（SUMO/CARLA/DTALite）。查看错误提示信息。

Q: 报告提交后能否修改？ A: 教师评阅前可以重新提交覆盖。评阅后不可修改。

Q: 算法脚本运行超时？ A: 算法执行有时间限制，请优化代码效率。避免无限循环。

Q: 忘记密码？ A: 联系教师或管理员重置密码。
