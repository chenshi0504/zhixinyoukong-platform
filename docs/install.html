智信优控 — 面向车路云一体化的综合交通实验平台 安装手册

版本：v3.3.3 | 更新日期：2026-04-14

一、系统要求

1.1 硬件要求

项目 最低要求 推荐配置
处理器 Intel i5 / AMD Ryzen 5 Intel i7 / AMD Ryzen 7
内存 8 GB 16 GB 及以上
硬盘空间 5 GB（仅平台） 25 GB（含外部仿真工具）
显卡 集成显卡（基础功能） NVIDIA 独立显卡，显存 ≥ 4 GB（CARLA 仿真必须）
网络 首次激活需联网 宽带网络（云端同步功能）

1.2 软件要求

项目 要求
操作系统 Windows 10 / 11（64 位）
.NET Framework 4.5 及以上（Windows 默认已包含）
VC++ 运行库 Visual C++ 2015-2022 Redistributable x64
DirectX 运行时 DirectX End-User Runtime（CARLA 用户必装）

二、平台安装

2.1 获取安装程序

安装包包含以下文件，请确保它们位于同一文件夹中：

installer/
├── 智信优控_本地_Setup_v3.3.3.exe     ← 安装程序主体
├── 智信优控_本地_Setup_v3.3.3-1.bin   ← 安装数据（必须与 exe 同目录）
├── env/
│   ├── config.local.env               ← 环境配置模板
│   └── 一键配置环境.bat               ← 自动配置脚本
├── data/                              ← 案例数据
│   ├── data.db                        ← 初始数据库
│   └── algorithms/                    ← 算法案例数据
├── software/                          ← 外部工具（DTALite 等）
└── docx/                              ← 使用文档

2.2 安装步骤

  1. 进入安装包目录，双击 智信优控_本地_Setup_v3.3.3.exe
  2. 选择安装目录
  • 推荐路径：D:\智信优控_本地 或其他非系统盘目录
  • 避免路径：C:\Program Files（可能存在写权限问题）
  1. 勾选"创建桌面快捷方式"（可选）
  2. 点击"安装"，等待安装完成（约 1-2 分钟）
  3. 安装完成后可选择立即启动

重要提示：.exe 和 .bin 文件必须在同一文件夹中，缺少 .bin 文件将导致安装失败。

2.3 复制案例数据

安装完成后，将案例数据复制到安装目录：

复制: data/data.db         →  <安装目录>/_internal/backend/data.db
复制: data/algorithms/     →  <安装目录>/_internal/backend/algorithms/

如果不复制案例数据，平台仍可启动，但部分模块（如数据融合）缺少示例数据。

三、环境配置

3.1 方式 A：一键配置（推荐）

  1. 进入安装包的 env/ 文件夹
  2. 双击 一键配置环境.bat
  3. 脚本将自动检测 Python 环境和 SUMO 安装路径，并生成配置文件

3.2 方式 B：手动配置

  1. 将 env/config.local.env 复制到安装目录（与 智信优控.exe 同级）
  2. 用文本编辑器打开，取消注释并填写以下配置：
# Python 算法环境路径（必填，算法子进程依赖此解释器）
ZXK_ALGO_PYTHON_EXE=D:\your_path\python.exe

# SUMO 安装根目录（信号优化/路径诱导/车速控制必填）
SUMO_HOME=C:\Program Files (x86)\Eclipse\Sumo

# CARLA 根目录（虚实结合仿真模块需要）
# CARLA_ROOT=D:\CARLA\WindowsNoEditor

# 云端管理平台 API 地址（本地-云端同步功能需要）
# CLOUD_API_URL=https://your-cloud-server.com

3.3 Python 算法环境要求

平台的算法模块（数据采集、预测、优化等）通过独立的 Python 子进程运行，需要一个已安装如下依赖的 Python 环境：

依赖 版本 用途
Python ≥ 3.9 运行环境
numpy - 数值计算
torch ≥ 2.0 深度学习算法（DQN/PPO）
ultralytics ≥ 8.0 YOLO11 目标检测
traci - SUMO 仿真控制（随 SUMO 安装）
scikit-learn - 机器学习算法

如果目标机器没有现成的 Python 环境，此步可暂时跳过。平台主体能正常启动，只是算法子进程会报错。

四、外部软件安装

4.1 VC++ 2015-2022 Redistributable（必装）

DTALite 等组件依赖 VC++ 运行库。

  • 下载地址：https://aka.ms/vs/17/release/vc_redist.x64.exe
  • 安装方式：双击运行，按默认设置安装
  • 验证：确认 C:\Windows\System32\mfc140.dll 存在

4.2 SUMO 交通仿真器（必装）

信号优化、路径诱导、车速控制、三层级协同控制等模块依赖 SUMO。

  • 版本：1.21.0 或更高
  • 下载地址：https://sumo.dlr.de/docs/Downloads.php
  • Windows 64-bit MSI：https://sumo.dlr.de/releases/1.21.0/sumo-win64-1.21.0.msi
  • 安装方式：双击 MSI 安装，默认路径即可
  • 环境变量：安装后设置 SUMO_HOME 指向安装目录（如 C:\Program Files (x86)\Eclipse\Sumo）
  • 验证：确认 %SUMO_HOME%\bin\sumo-gui.exe 存在

一键配置脚本可自动检测 SUMO 路径。

4.3 CARLA 仿真器（虚实结合模块需要）

CARLA 用于自动驾驶虚实结合仿真场景构建。

硬件要求：

  • NVIDIA 显卡，显存 ≥ 4 GB（推荐 ≥ 6 GB）
  • 约 15 GB 磁盘空间

安装步骤：

  1. 下载 CARLA 0.9.15（Windows 版，约 15 GB）
  • 下载页面：https://github.com/carla-simulator/carla/releases/tag/0.9.15/
  • 文件名：CARLA_0.9.15.zip
  1. 解压到目标目录（如 D:\CARLA\CARLA_0.9.15\WindowsNoEditor）
  2. 设置环境变量 CARLA_ROOT 指向解压目录
  3. 验证：确认 %CARLA_ROOT%\CarlaUE4.exe 存在

前置依赖：

  • VC++ 2015-2022 Redistributable（见 4.1）
  • DirectX End-User Runtime
  • 下载地址：https://www.microsoft.com/en-us/download/details.aspx?id=35
  • 安装后确认 C:\Windows\System32\d3dx9_43.dll 存在

4.4 DTALite + NEXTA（交通流重构）

  • 安装包中 software/dtalite/ 目录已自带完整工具
  • 将该目录解压/复制到安装目录的对应位置即可
  • 无需额外配置环境变量

4.5 CUDA Toolkit（可选，GPU 加速）

仅在使用 DQN、PPO 等深度强化学习算法时需要。

  • 版本要求：≥ 11.8（需与 PyTorch 版本匹配）
  • 下载地址：https://developer.nvidia.com/cuda-toolkit
  • 验证：运行 nvidia-smi 确认 CUDA 可用

八、常见问题

Q1: 安装后双击 exe 没有反应？ A: 检查是否安装在 C:\Program Files 下。由于写权限限制，建议安装到 D:\ 或其他非系统目录。

Q2: 启动后显示"后端服务未启动"？ A: 后端服务需要 5-10 秒初始化时间，请稍等。如持续显示，检查端口 8000 是否被其他程序占用。

Q3: 算法模块报错"Python 未找到"？ A: 检查 config.local.env 中的 ZXK_ALGO_PYTHON_EXE 是否指向有效的 Python 路径。可通过一键配置脚本自动配置。

Q4: SUMO 仿真无法启动？ A: 确认已安装 SUMO 并设置了 SUMO_HOME 环境变量。验证方法：打开命令行输入 echo %SUMO_HOME%，应显示 SUMO 安装路径。

Q5: CARLA 启动后黑屏或崩溃？ A: (1) 检查 GPU 显存是否 ≥ 4 GB；(2) 笔记本用户请切换到独立显卡；(3) 确认已安装 DirectX End-User Runtime。

Q6: DTALite 报错缺少 mfc140.dll？ A: 安装 VC++ 2015-2022 Redistributable（见第四节 4.1）。

Q7: 数据融合模块提示缺少数据？ A: 请按第二节 2.3 的说明将案例数据复制到安装目录。

Q8: 激活失败？ A: 检查网络连接是否正常，确认 License Key 正确且未被其他机器使用。

Q9: 如何修改平台端口？ A: 在 config.local.env 中设置 LOCAL_APP_PORT=自定义端口号，然后重启平台。

Q10: 本地平台如何连接云端管理平台？ A: 在 config.local.env 中设置 CLOUD_API_URL 为云端平台的实际地址（如 https://your-server.com:9000），重启后本地平台会自动同步教学任务和实验报告。

九、卸载

  1. 打开 Windows 设置 → 应用 → 已安装的应用
  2. 搜索"智信优控"，点击"卸载"
  3. 按提示完成卸载
  4. 如需清除残留数据，手动删除安装目录
