# 智信优控 — 教师使用手册

> 适用版本：v1.0 | 更新日期：2026-02-22

---

## 一、登录系统

1. 启动软件（双击桌面快捷方式或 `智信优控.exe`）
2. 等待加载完成，自动跳转到登录页面
3. 输入教师账号和密码，角色选择"教师"
4. 点击"登录系统"

默认教师账号：`teacher` / `teacher123`（首次登录后请立即修改密码）

---

## 二、教师首页概览

登录后进入教师首页，左侧导航栏包含以下功能模块：

| 功能区域 | 说明 |
|----------|------|
| 实验功能模块 | 10个交通实验功能（信号优化、路径诱导等） |
| 教学任务管理 | 发布/编辑/删除教学任务 |
| 实验报告管理 | 查看/评阅学生提交的实验报告 |
| 学生信息管理 | 查看学生列表、批量导入学生 |
| 操作说明文档 | 平台使用帮助 |

---

## 三、教学任务管理

### 3.1 发布新任务

1. 进入"教学任务管理"页面
2. 点击"新建任务"按钮
3. 填写任务信息：
   - 任务标题（必填）
   - 任务描述（实验要求、步骤说明等）
   - 截止日期
   - 关联的实验模块（如"交通信号优化"）
4. 点击"发布"，任务将推送给所有学生

### 3.2 管理已有任务

- 任务列表显示所有已发布的任务
- 可以查看每个任务的提交情况（已提交/未提交人数）
- 支持编辑任务内容、修改截止日期
- 支持删除任务（已有提交的任务请谨慎删除）

---

## 四、实验报告管理

### 4.1 查看报告列表

1. 进入"实验报告管理"页面
2. 报告列表显示所有学生提交的实验报告
3. 可按任务名称、学生姓名、提交状态筛选

### 4.2 评阅报告

1. 点击某份报告的"评阅"按钮
2. 查看报告内容（实验数据、截图、分析等）
3. 填写评分（0-100分）和评语
4. 点击"提交评阅"保存

### 4.3 下载报告

- 点击"下载"按钮可下载学生提交的报告附件
- 支持批量查看报告统计（平均分、提交率等）

---

## 五、学生信息管理

### 5.1 查看学生列表

- 显示所有已注册的学生账号
- 可查看学生姓名、学号、班级等信息

### 5.2 批量导入学生

1. 准备Excel文件（.xlsx），包含列：用户名、密码、姓名
2. 点击"批量导入"按钮
3. 选择Excel文件上传
4. 系统自动创建学生账号

## 六、实验功能模块使用

教师可以使用所有10个实验功能模块进行教学演示：

### 6.1 多源数据采集
- 基于YOLOv8/YOLO11的视频目标检测
- 上传视频文件，系统自动识别车辆、行人等交通目标
- 输出检测结果和统计数据

### 6.2 多源数据融合
- 贝叶斯融合算法
- 融合多种传感器数据（视频、雷达、GPS等）

### 6.3 交通流重构
- 基于DTALite的OD矩阵反推
- 需要安装DTALite/NEXTA软件
- 上传路网数据和观测数据，输出重构的交通流

### 6.4 交通流预测
- 支持多种预测模型
- 输入历史交通数据，输出未来时段的交通流预测

### 6.5 交通信号优化
- 支持TuRBO/BO/DQN/PPO/GA/PSO等多种算法
- 需要安装SUMO仿真软件
- 配置路网和信号方案，运行优化，查看仿真结果

### 6.6 路径诱导
- 支持Dijkstra/SSP/A*等路径算法
- 在SUMO路网中计算最优路径

### 6.7 车速控制
- 支持IDM/ACC/CACC/PID等控制模型
- SUMO + TraCI实时控制车辆速度

### 6.8 三层级协同优化
- 信号优化 + 路径诱导 + 车速控制联合优化
- 综合性实验，展示多层级协同效果

### 6.9 虚实结合仿真场景构建
- CARLA + SUMO联合仿真
- 需要安装CARLA仿真软件
- 构建虚实结合的交通场景

### 6.10 车规级智能车辆控制
- 基于CARLA的车辆控制实验
- 待完整接入

## 七、常见问题

**Q: 发布的任务学生看不到？**
A: 确认任务状态为"已发布"。如果使用云端同步，需要学生联网后才能接收。

**Q: 无法评阅报告？**
A: 确认学生已提交报告。报告状态为"已提交"才可评阅。

**Q: SUMO/CARLA仿真无法启动？**
A: 确认已安装对应软件并设置了环境变量（SUMO_HOME / CARLA_ROOT）。

**Q: 如何修改密码？**
A: 联系管理员重置密码，或通过管理员页面修改。
